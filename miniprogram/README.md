# 守护咪小程序

用爱守护每一只流浪猫 🐱

## 项目简介

"守护咪"是一款专注于流浪猫救助的微信小程序，结合科学养宠知识、法律援助工具和社区互动功能，为流浪猫救助志愿者和爱猫人士提供全方位的支持。

### 核心理念

- 科学救助：传播正确的养宠和救助知识
- 法律保护：用法律武器打击虐猫行为
- 社区互助：营造温暖有爱的救助氛围
- TNR推广：倡导"诱捕-绝育-放归"的科学理念

## 功能特色

### 1. 守护雷达 📡
- 基于地理位置的风险预警地图
- 三级风险标注（低危/中危/高危）
- 模糊地理位置保护猫咪安全
- 实时风险区域提醒

### 2. 猫咪百科 📚
**品种图鉴**
- 8种常见猫咪品种介绍
- 性格特点、寿命、饲养建议

**行为语译**
- 10种猫咪常见行为解读
- 专业建议和注意事项

**禁忌清单**
- 4大类有害物质详解
- 基于ASPCA和ISFM权威标准
- 包含中毒症状和处理方法

### 3. 科学养宠 🏥
**医疗常识**
- 疫苗接种时间表
- 驱虫计划（体内/体外/心丝虫）
- TNR理念宣传

**应急指南**
- 6种紧急情况处理方法
- 详细步骤和警示信息
- 包括：奶猫救助、呕吐、外伤、中暑、中毒、误食异物

**封窗行动**
- 高空坠猫数据警示
- 5大科学封窗标准
- 常见误区纠正

### 4. 守护盾牌 🛡️
**反虐指南**
- 5步正确取证流程
- 报警话术模板（可一键复制）
- 紧急联系方式

**法律援助**
- 4条相关法律法规详解
- 具体条文和处罚标准
- 5步维权流程
- 专业机构推荐

**提防手册**
- 5种可疑行为识别
- 10个伪装领养人特征
- 10项安全领养检查清单

### 5. 咪咪议事厅 💬
**今日份吸猫**
- 用户动态分享
- 点赞评论互动

**云养打卡**
- 待领养猫咪展示
- 云养护进度追踪

**互助问答**
- 养猫问题求助
- 社区互助解答

## 数据标准

所有科普内容均参考权威机构：

- **动物医疗**：ISFM（国际猫医学会）标准
- **有害物质**：ASPCA（美国防止虐待动物协会）数据
- **法律条文**：中国现行法律法规
- **救助理念**：国内主流公益组织准则

## 开发指南

### 环境要求
- 微信开发者工具
- Node.js（用于未来可能的云开发）

### 本地运行
1. 使用微信开发者工具打开项目
2. 填入自己的 AppID
3. 编译运行

### 注意事项
1. 地图功能需要配置位置权限
2. 部分功能依赖后端接口（目前为示例数据）
3. 图标资源需要自行准备或使用占位图
