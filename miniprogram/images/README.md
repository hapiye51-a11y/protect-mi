# 图片资源说明

本小程序需要以下图片资源，请将对应图片放置在 `/images/` 目录下。

## 必需图片列表

### 1. 登录页面
- **logo.png** - 小程序 Logo（建议尺寸：512x512px）
  - 用途：登录页面中央展示
  - 格式：PNG（支持透明背景）
  - 设计建议：猫咪相关的温馨图标

- **wechat-icon.png** - 微信图标（建议尺寸：128x128px）
  - 用途：登录按钮上的微信图标
  - 格式：PNG
  - 可从微信官方设计资源下载

### 2. 用户头像
- **default-avatar.png** - 默认头像（建议尺寸：256x256px）
  - 用途：未登录或未设置头像时的默认头像
  - 格式：PNG
  - 设计建议：可爱的猫咪剪影或通用头像

### 3. 地图标记图标（可选）
如需自定义地图标记，请准备以下图标：

- **marker-high.png** - 高危区域标记（建议尺寸：64x64px）
  - 颜色：红色系

- **marker-medium.png** - 中危区域标记（建议尺寸：64x64px）
  - 颜色：橙色系

- **marker-low.png** - 低危区域标记（建议尺寸：64x64px）
  - 颜色：黄色系

- **marker-cat.png** - 猫咪点位标记（建议尺寸：64x64px）
  - 设计：猫咪图标

- **marker-rescue.png** - 救助信息标记（建议尺寸：64x64px）
  - 设计：救助相关图标

- **icon-location.png** - 定位图标（建议尺寸：64x64px）
  - 用途：地图页面定位按钮

## 快速创建占位图

如果暂时没有设计图片，可以使用以下方法创建占位图：

### 方法1：使用在线图标生成器
- **Logo**: https://looka.com (AI Logo 生成器)
- **头像**: https://api.dicebear.com/7.x/avataaars/svg?seed=cat
- **图标**: https://www.flaticon.com (免费图标库)

### 方法2：使用纯色占位图
创建简单的纯色PNG图片作为临时占位：
- Logo: 橙色圆形 + "守护咪" 文字
- 头像: 灰色圆形
- 图标: 对应颜色的圆点

### 方法3：使用emoji表情
微信小程序支持emoji，可以临时使用emoji代替图标：
- 🐱 猫咪
- ⚠️ 警告
- 📍 定位
- 💬 微信

## 图片规范

### 尺寸要求
- **Logo**: 512x512px (1:1)
- **头像**: 256x256px (1:1)
- **图标**: 64x64px (1:1)

### 格式要求
- **推荐**: PNG (支持透明背景)
- **可选**: JPG (不需要透明背景的图片)
- **不推荐**: GIF (动图会增加包体积)

### 文件大小
- Logo: < 100KB
- 头像: < 50KB
- 图标: < 20KB

### 颜色规范
- **主色调**: #FF9800 (橙色)
- **辅助色**: #FFB74D (浅橙色)
- **高危**: #FF5252 (红色)
- **中危**: #FF9800 (橙色)
- **低危**: #FFC107 (黄色)
- **安全**: #4CAF50 (绿色)

## 注意事项

1. 所有图片必须放在 `/images/` 目录下
2. 图片命名使用小写字母和连字符（kebab-case）
3. 微信小程序包体积限制为2MB，注意图片大小
4. 建议使用压缩工具优化图片：https://tinypng.com
5. 上传前检查图片是否符合微信小程序规范
