# 守护咪 - 流浪猫救助小程序

## 项目愿景

通过技术力量抵制虐猫，保护流浪动物。我们致力于利用移动互联网技术，为流浪猫提供一个温暖的庇护所，让每一只流浪猫都能得到应有的关爱和保护。

## 项目简介

"守护咪"是一款专注于流浪猫救助的微信小程序，通过地图定位、信息发布、知识科普等功能，连接爱心人士与需要帮助的流浪猫，共同构建一个关爱动物的社会环境。

## 核心功能

### 1. 守护雷达（首页）
- **地图定位**：实时显示用户位置及附近的流浪猫信息
- **发布救助**：快速发布流浪猫救助信息
- **反虐指南**：提供动物保护相关法律法规和应对措施
- **猫咪科普**：普及猫咪养护知识和健康常识

### 2. 个人中心
- **用户信息**：展示用户头像、昵称等基本信息
- **数据统计**：记录用户发布救助、帮助次数、关注猫咪等数据
- **我的发布**：查看和管理用户发布的救助信息
- **我的关注**：查看关注的流浪猫动态
- **救助历史**：回顾参与过的救助活动
- **设置**：个性化配置和隐私设置

## 技术栈

- **框架**：微信小程序原生框架（WXML, WXSS, JS, JSON）
- **地图组件**：微信小程序 map 组件
- **云开发**：微信云开发（待配置）
- **UI 设计**：温暖简洁的视觉风格，符合中国用户审美

## 开发指南

### 环境要求
- 微信开发者工具（最新版本）
- 微信小程序账号
- Node.js（如需使用云开发）

### 快速开始

1. 克隆项目到本地
```bash
git clone [项目地址]
cd protect-mi
```

2. 使用微信开发者工具打开项目

3. 在 project.config.json 中配置你的 appid

4. 配置云开发环境（如需要）

### 配置说明

#### project.config.json
- `appid`：小程序 AppID
- `projectname`：项目名称
- `miniprogramRoot`：小程序根目录（默认为 miniprogram）

#### app.json
- `pages`：页面路径配置
- `window`：全局窗口样式配置
- `tabBar`：底部导航栏配置

## 设计理念

### 视觉风格
- **主色调**：橙色 (#FF9800) - 代表温暖、活力和希望

- **背景色**：米白色 (#FFF8F0) - 柔和舒适
- **圆角设计**：20rpx - 符合现代 UI 设计趋势

### 交互体验
- 简洁直观的操作流程
- 温暖友好的视觉反馈
- 快速响应的交互体验
